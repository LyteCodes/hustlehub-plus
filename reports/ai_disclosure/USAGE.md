## Disclosure of AI Usage

AI usage must be documented as as markdown file entries in this directory, using the format below:

```md
Disclosure of AI Usage in my Assessment:  

Sections: Section(s) within the assessment in which generative AI was used, e.g. Conclusion, `source.cs` lines x - y, etc.  
Name of AI tool(s) used: Name of AI tool(s) used.  
Purpose/intention behind use: Purpose/intention behind use, e.g.  Brainstorming; Meaning making; Initial investigation; Correcting grammar and spelling; Sourcing ideas for xyz (structure; design, etc.)  
Date(s) in which generative AI was used: yyyy-MM-dd  
A link or screenshot to the actual generative AI chat: https://generic.ai/share/xyz  
```
